# Polyend Tracker

A little space for my experiments, tools and other bits and pieces for the **Polyend Tracker**.

With Polyend opening up the Tracker software, I wanted to make a place to share some of the things I create and discover while exploring what can be done with it.

## What's planned?

I'm hoping to put together a few **`.ptfx` files** soon, along with any other useful tidbits that come out of experimenting with the Tracker.

This might include:
- `.ptfx` patches and experiments
- Small tools and utilities
- Notes, discoveries and useful resources
- Anything else I find worth sharing

There's not much here just yet, but I'll add things as I make them. It's intended to be an informal collection rather than a polished software project.
